# 4-PLAYERMULTIPLAYER-GAME
This game is 4 player tag game which allows 4 people to play together and tag each other and whoever is last on being it when it reaches 0 seconds lose the whole game.

# CONTROLS
For Player 2 
W key is for jump, A key is to go left, D key is to go right

For Player 1
Up arrow key is jump, left arrow key is going left, right arrow key is to go right

For Player 3
I key is for jump, J key is to go left, L key is to go right

For Player 4
1 key is to go left, 2 key is to jump, 3 key is to go right
